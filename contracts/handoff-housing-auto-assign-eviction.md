## 2. النقاط باختصار

كلها عبر البوابة، `Authorization: Bearer <JWT>`. الـ enums أرقام.

### أدمن — لوحة التسكين
```
POST /api/allocations/auto-assign
Body: { "dryRun": true }   ← معاينة، صفر كتابة
      { "dryRun": false }  ← تنفيذ + إشعارات حقيقية
```
الرد `AutoAssignResultDto`: `placedTargets`, `housedStudents`, `skippedTargets`, `assignments[]`, `skipped[{ targetType, targetId, size, reason }]`.
تدفّق مقترح: زر «معاينة» → عرض الجدول → زر «تنفيذ».

### أدمن — قائمة الطلبات
- فلترة الرفض: `GET /api/housing-requests?admissionStatus=3` ثم صنّف بالواجهة على `decision.rejectionReason`:
  - `1` → مطرود لعدم الدفع · `0` / `null` → رفض مراجعة.
- (لا يوجد باراميتر سيرفر لـ `rejectionReason`.)

### طالب (Flutter)
- `GET /api/housing-requests/mine` → إذا `decision.status == 3` و `decision.rejectionReason == 1`:
  رسالة: «تم إلغاء تخصيصك لعدم دفع الرسوم خلال المهلة. يمكنك التقديم من جديد في دورة قادمة.» — أخفِ أزرار الدفع/التعديل.
- `GET /api/allocations/mine` → `404` بعد الطرد.
- `POST /api/housing-requests/{id}/pay` بعد الطرد → `400`.
