# توثيق خدمات المنصّة — مادّة الأطروحة

مجموعة مستندات، ملفٌ لكل خدمة، تُوثّق ما أُنجِز في «منصة إدارة شؤون المدينة الجامعية» — جامعة حلب، كلية الهندسة المعلوماتية.

كل مستند خدمة يغطّي: نظرة عامة وموقع الخدمة في المعمارية، النموذج البرمجي وعلاقات الجداول (ERD وصفي)، قواعد العمل، حالات الاستخدام، مرجع نقاط الـ API والصلاحيات، التكامل مع الخدمات الأخرى، القرارات التصميمية ومبرّراتها، ثم القيود والأعمال المستقبلية.

## ملاحظات

- **AuthService** (المصادقة، المستخدمون، الأدوار، المحفظة) خدمة خارجية مبنيّة بـ Node.js، خارج نطاق هذا المستودع؛ يُشار إليها في كل مستند حيثما يوجد تكامل.
- التقنية الموحّدة لكل خدمات هذا المستودع: ASP.NET Core (.NET 9) + EF Core + SQL Server، بنمط Controller/Service/Repository.
- كل خدمة لها قاعدة بيانات مستقلّة؛ التكامل بينها عبر HTTP فقط.
